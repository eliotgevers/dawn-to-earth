Source identity includes the evidence record, unit, revision, archive and run contents. Use `db:coverage` to see which selectable scopes actually contain clocked evidence and `python3 apps/backend/scripts/sync.py verify` to check those runs in Grafana.

The image analysis uses SHA-256-identified local files. The seed includes per-tile count, sum and sum of squares over a documented caption region. For a new image edition, decode the image to 8-bit RGB and divide the caption rectangle into an 8 × 4 grid in row-major order. Compute cell boundaries by integer division. For each pixel use integer luminance `(2126R + 7152G + 722B + 5000) // 10000`; store the count, sum and sum of squares for each cell. Fresh database bootstrap consumes the checked-in measurements and verifies image hashes. A saved finding identifies the source issue, exact run editions, frame window, alignment, selected caption region, quantity, analyst and paired measurements. Frame positions have no time calibration.

The Aule caption export and Aurora receipt export retain counts of document fields at their recorded offsets. PP14-A and PP14-D retain the original normalized archive readings.
