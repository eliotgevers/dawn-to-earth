## What a link carries

A spacecraft communications system can carry housekeeping information about the vehicle and data from the mission payload. These categories answer different questions: one helps describe spacecraft state, while the other contains the observations the mission was built to make.

An orbital pass is not the same as a successful data transfer. Visibility describes the geometry between a spacecraft and a receiver. Reception and interpretation also depend on the applicable systems and source metadata. For an offline record, a reviewer can ask which spacecraft or fixture produced a file, which capture it belongs to, and whether its file type or version is documented.
