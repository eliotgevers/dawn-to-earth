## The agreed definition at a point in time

A configuration baseline is a formally agreed reference for a system or product at a particular stage. A baseline lets a team compare a proposed change against something specific and lets reviewers know what definition their evidence refers to.

A current version label does not establish that previously assembled units use that version. Design baselines, serialized build records, and evidence captures represent different concerns. Each link can be useful: the build points to the definition it used, and the evidence points to the observed build when known. If applicability is unclear, leave it unresolved rather than quietly substituting the current revision.

## Fictional example

Kea Rev B is the current definition in one build group. An existing Rev A carrier still retains its original baseline and evidence links.
