## The boundary between subsystems

An interface is where parts of the system interact. It can describe how an instrument fits its support, who provides power, where heat crosses a boundary, or how two teams identify the same data product. A compatibility claim involves both sides.

An interface record gives the teams a shared reference for names, ownership, applicable revisions, and evidence. A change to either side can affect the agreement. In a review, it is useful to separate the agreed interface from an observation about one assembled article. The former defines what should be compatible; the latter is limited to the configuration that was observed.

## Reading an interface record

NASA’s handbook describes interface management as an agreement between the parties on both sides of the boundary. For a reviewer, three questions follow. Which revisions are expected to be compatible? Which party owns a change? What evidence supports the compatibility claim? The affected parties should be able to recognize the same boundary in both their records.

Dawn’s public product overview describes standardized interfaces for SatDrive and an engineering model representing aspects of the satellite interface. This gives a public example of the distinction between a shared boundary and the means of collecting evidence about it. See [Dawn Aerospace’s civil satellite work](../space/dawn-civil-satellite-work.md).
