## An index with meaning

A manifest identifies the contents of a packet and their relationship to the rest of the record. It helps separate an original capture from a derived summary, records which file a review actually considered, and provides a stable pointer when attachments are stored elsewhere.

An archive index is especially valuable when filenames repeat. A local export can be readable and still lack enough metadata to establish where it came from. If the source is unknown, record that gap. File presence alone is insufficient evidence that the reviewed version matches the delivered version.

## Fictional example

Weka’s offline replay export is present, but the manifest is missing the pointer to the source capture. The handoff records that gap explicitly.
